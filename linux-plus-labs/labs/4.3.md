## Lab 4.3: Python Basics for System Administration {#lab-4-3}

::: labinfo
**Objective:** 4.3 Summarize Python basics used for Linux system administration.\
**Domain:** 4.0 Automation, Orchestration, and Scripting (17% of the exam)\
**Time:** about 2 hours\
**VM:** ubuntu-lab\
**Snapshot first:** Not required. Everything happens in your home directory, plus two small apt packages.

Python is the second language of Linux administration after Bash. Ansible, cloud-init, firewalld, and many vendor tools are written in it, and it is the natural choice when a script outgrows Bash: when you need real data structures, JSON, web APIs, or clean error handling. In this lab you explore Python's data types, write admin scripts with built-in modules, install third-party packages safely in a virtual environment, build your own package, and check your code against the PEP 8 style guide.

### What you'll practice

- Fundamentals: indentation, current versions (Python 3)
- Data types: Boolean, Dictionary, Floating point, Integer, List, String
- Built-in modules (`os`, `sys`, `shutil`, `subprocess`, `pathlib`, `json`, `argparse`, `datetime`, `socket`, `platform`)
- Virtual environment (`venv`)
- Installing dependencies (`pip install`, `requirements.txt`)
- Extensible using modules and packages
- PEP 8 (checked with `flake8` and `pycodestyle`)

### How it works

Python is an **interpreted** language: you write a `.py` text file, and the `python3` program reads and runs it line by line. There is no compile step. Python 2 reached end of life in January 2020; every current distribution ships **Python 3** (Ubuntu 24.04 has Python 3.12, Rocky 9 has 3.9 with newer versions available). The command is `python3`. On many systems plain `python` does not exist at all, or points to Python 3 only if a compatibility package is installed.

Python has two features that surprise people coming from Bash:

1. **Indentation is syntax.** Bash ends blocks with words like `fi` and `done`. Python uses a colon `:` to start a block and the indentation of the following lines to show what belongs to it. PEP 8 says to use 4 spaces per level. Mixing levels causes an `IndentationError`.
2. **Values have types.** Bash treats almost everything as a string. Python knows whether a value is an integer, a floating-point number, a string, a Boolean, a list, or a dictionary, and each type has its own operations.

| Type | Python name | Example | Typical admin use |
|---|---|---|---|
| Integer | `int` | `42` | port numbers, counts, UIDs |
| Floating point | `float` | `0.75` | percentages, load averages |
| String | `str` | `"ubuntu-lab"` | host names, paths, log lines |
| Boolean | `bool` | `True` / `False` | is the service running? |
| List | `list` | `["ssh", "cron"]` | an ordered group of items |
| Dictionary | `dict` | `{"ip": "10.0.0.5"}` | key-value data, parsed JSON |

Python is **extensible using modules and packages**. A **module** is simply a `.py` file whose functions you can `import`. A **package** is a directory of modules with an `__init__.py` file. Python's **standard library** comes with hundreds of **built-in modules** ("batteries included"): `os` and `sys` talk to the operating system and interpreter, `subprocess` runs commands, `pathlib` handles files and paths, `json` reads and writes JSON, `argparse` parses command-line options, and so on. Anything else (for example `requests` for web APIs or `psutil` for system metrics) comes from the **Python Package Index (PyPI)** and is installed with `pip`.

Installing packages with `pip` into the system Python can break tools the OS depends on, because apt and pip would fight over the same files. Since Ubuntu 23.04 and Debian 12, the system Python is marked **externally managed** (PEP 668), and `pip install` refuses to touch it. The solution is a **virtual environment** (venv): a private folder with its own copy of the `python` and `pip` commands and its own `site-packages` directory.

```{.diagram}
 System Python (apt-managed)          ~/labs/4.3/venv  (yours)
 /usr/bin/python3                     venv/bin/python  -> links to /usr/bin/python3.12
 /usr/lib/python3/dist-packages       venv/lib/python3.12/site-packages
   python3-apt, python3-yaml ...        requests, psutil, flake8 ...
          ^                                     ^
     apt install python3-xyz            pip install xyz  (after: source venv/bin/activate)
```

Each project gets its own venv, so two projects can use different versions of the same library. You record a project's **dependencies** in `requirements.txt` so anyone can rebuild the same venv with one command.

Finally, **PEP 8** is the official style guide for Python code (PEP means Python Enhancement Proposal). It covers 4-space indentation, line length (79 characters), naming (`snake_case` for functions and variables, `CapWords` for classes, `UPPER_CASE` for constants), spaces around operators, and blank lines between functions. Tools like `pycodestyle` and `flake8` check it automatically.

2. Write a correct script that shows `if`/`elif`/`else`, a `for` loop, a function, and exit codes. The file is `~/labs/4.3/services.py`:

    ```bash
    cat > services.py <<'EOF'
    #!/usr/bin/env python3
    """services.py - report whether some systemd services are active."""

    import subprocess
    import sys

    SERVICES = ["ssh", "cron", "systemd-journald", "nosuch"]


    def is_active(name):
        """Return True if systemctl reports the service as active."""
        result = subprocess.run(["systemctl", "is-active", "--quiet", name])
        return result.returncode == 0


    def main():
        """Check every service and return the number that are down."""
        down = 0
        for name in SERVICES:
            if is_active(name):
                print(f"{name:<17} active")
            elif name.startswith("no"):
                print(f"{name:<17} (test name that does not exist)")
                down += 1
            else:
                print(f"{name:<17} NOT active")
                down += 1
        return down


    if __name__ == "__main__":
        sys.exit(main())
    EOF
    chmod +x services.py
    ./services.py
    echo "exit status: $?"
    ```

    ```{.output}
    ssh               active
    cron              active
    systemd-journald  active
    nosuch            (test name that does not exist)
    exit status: 1
    ```

    ::: explain
    **What just happened:** Read the script by its indentation. `def is_active(name):` defines a **function**; its body is the indented lines below it. The text in triple quotes right after `def` is a **docstring** that documents the function. `subprocess.run([...])` runs a command, passing each argument as a separate list item (no shell, so no quoting problems), and `.returncode` holds its exit status. `main()` returns a count, and `sys.exit(main())` turns that count into the script's exit status, so Bash and cron can test it with `$?`. The block `if __name__ == "__main__":` runs only when the file is executed directly, not when another script imports it.
    :::

    ::: tip
    `ssh` might show `NOT active` if your VM starts SSH by socket activation (`ssh.socket`) and no one has connected yet. Since you are probably logged in over SSH, it should be active.
    :::

2. Write a real admin tool, `diskreport.py`, that uses six built-in modules. Read the comments and docstrings as you type or paste it.

    ```bash
    cat > diskreport.py <<'EOF'
    #!/usr/bin/env python3
    """diskreport.py - report disk usage for one or more mount points."""

    import argparse
    import datetime
    import json
    import shutil
    import socket
    import sys

    GIB = 1024 ** 3


    def usage_for(path):
        """Return a dictionary describing disk usage for path."""
        total, used, free = shutil.disk_usage(path)
        return {
            "path": path,
            "total_gib": round(total / GIB, 1),
            "used_gib": round(used / GIB, 1),
            "free_gib": round(free / GIB, 1),
            # same formula as df: used / (used + available to normal users)
            "percent_used": round(used / (used + free) * 100, 1),
        }


    def parse_args():
        """Define and read the command-line options."""
        parser = argparse.ArgumentParser(description="Report disk usage.")
        parser.add_argument("paths", nargs="*", default=["/"],
                            help="mount points to check (default: /)")
        parser.add_argument("-t", "--threshold", type=float, default=80.0,
                            help="warn at or above this percent (default: 80)")
        parser.add_argument("--json", action="store_true",
                            help="print JSON instead of a table")
        return parser.parse_args()


    def main():
        """Build the report and return an exit code."""
        args = parse_args()
        results = []
        for path in args.paths:
            try:
                results.append(usage_for(path))
            except FileNotFoundError:
                print(f"warning: {path} does not exist", file=sys.stderr)

        over = [r for r in results if r["percent_used"] >= args.threshold]

        if args.json:
            report = {
                "host": socket.gethostname(),
                "time": datetime.datetime.now().isoformat(timespec="seconds"),
                "threshold": args.threshold,
                "filesystems": results,
            }
            print(json.dumps(report, indent=2))
        else:
            print(f"{'PATH':<10}{'SIZE':>8}{'USED':>8}{'FREE':>8}{'USE%':>7}")
            for r in results:
                flag = "  <-- over threshold" if r in over else ""
                print(f"{r['path']:<10}{r['total_gib']:>8}{r['used_gib']:>8}"
                      f"{r['free_gib']:>8}{r['percent_used']:>6}%{flag}")

        return 1 if over else 0


    if __name__ == "__main__":
        sys.exit(main())
    EOF
    chmod +x diskreport.py
    ```

    ::: explain
    **What just happened:** Here is what each built-in module does in this script:

    - `shutil.disk_usage()` returns total, used, and free bytes. The line `total, used, free = ...` unpacks three values at once.
    - `argparse` turns command-line arguments into `args.paths`, `args.threshold`, and `args.json`, and generates `--help` for free. `type=float` converts the option's text to a float.
    - `json.dumps()` converts a dictionary into JSON text.
    - `datetime` gives the current time; `socket.gethostname()` the host name.
    - `sys.stderr` and `sys.exit()` send warnings to standard error and set the exit status.

    The function returns a **dictionary** per file system, and `results` is a **list** of those dictionaries. `over = [r for r in results if ...]` is a **list comprehension**: a one-line loop that builds a new list of the items that pass the test. `try` / `except FileNotFoundError` catches a bad path instead of crashing.
    :::

#### Task 5: Use third-party packages in a script

1. Write `check_versions.py`, which uses `psutil` for system metrics and `requests` to call the PyPI web API.

    ```bash
    cd ~/labs/4.3
    cat > check_versions.py <<'EOF'
    #!/usr/bin/env python3
    """check_versions.py - show system load and compare packages with PyPI."""

    import sys
    from importlib.metadata import version

    import psutil
    import requests

    PACKAGES = ["requests", "psutil"]


    def latest_on_pypi(name):
        """Ask the PyPI JSON API for the newest version of a package."""
        url = f"https://pypi.org/pypi/{name}/json"
        response = requests.get(url, timeout=10)
        response.raise_for_status()
        return response.json()["info"]["version"]


    def main():
        """Print memory, CPU, and package version information."""
        mem = psutil.virtual_memory()
        print(f"CPU cores: {psutil.cpu_count()}, CPU busy: "
              f"{psutil.cpu_percent(interval=1)}%")
        print(f"Memory used: {mem.percent}% of {mem.total // 1024 ** 2} MiB")
        for name in PACKAGES:
            installed = version(name)
            try:
                latest = latest_on_pypi(name)
            except requests.RequestException as err:
                print(f"{name}: cannot reach PyPI ({err})", file=sys.stderr)
                continue
            status = "up to date" if installed == latest else f"{latest} available"
            print(f"{name:<9} installed {installed:<8} {status}")


    if __name__ == "__main__":
        main()
    EOF
    ```

    ::: explain
    **What just happened:** Imports are grouped as PEP 8 recommends: standard library first (`sys`, `importlib.metadata`), then a blank line, then third-party packages. `from importlib.metadata import version` imports one function from a module. `requests.get()` makes an HTTPS request; `timeout=10` stops it hanging forever, and `raise_for_status()` turns an HTTP error (like 404) into an exception. `.json()` parses the reply into a **dictionary**, so `["info"]["version"]` digs out one value. `except requests.RequestException` handles network failures cleanly.
    :::

    """Disk usage helpers."""

    import shutil

    GIB = 1024 ** 3


    def usage_for(path):

        total, used, free = shutil.disk_usage(path)
        return {
            "path": path,
            "total_gib": round(total / GIB, 1),
            "free_gib": round(free / GIB, 1),

2. Add a module that uses `os`, `platform`, `subprocess`, and `pathlib`.

    ```bash
    cat > labtools/system.py <<'EOF'
    """Facts about the running Linux system."""

    import os
    import platform
    import subprocess
    from pathlib import Path


    def os_name():
        """Return PRETTY_NAME from /etc/os-release."""
        for line in Path("/etc/os-release").read_text().splitlines():
            if line.startswith("PRETTY_NAME="):
                return line.split("=", 1)[1].strip('"')
        return "unknown"


    def uptime():
        """Return the output of 'uptime -p' as a string."""
        result = subprocess.run(["uptime", "-p"], capture_output=True,
                                text=True, check=True)
        return result.stdout.strip()


    def summary():
        """Return a dictionary of basic system facts."""
        return {
            "os": os_name(),
            "kernel": platform.release(),
            "user": os.environ.get("USER", "unknown"),
            "uid": os.getuid(),
            "uptime": uptime(),
            "load_1min": round(os.getloadavg()[0], 2),
        }
    EOF
    ```

    ::: explain
    **What just happened:** `pathlib.Path(...).read_text()` reads a whole file in one call, and `.splitlines()` makes a list of lines. `line.split("=", 1)[1]` takes everything after the first `=`, and `.strip('"')` removes the quotes. `subprocess.run(..., capture_output=True, text=True, check=True)` captures the command's output as a string and raises an error if it fails. `os.environ` is a dictionary of **environment variables**, the same ones Bash exports. `os.getuid()` returns your UID.
    :::

3. Rewrite it in clean PEP 8 style, and check it again.

    ```bash
    cat > messy.py <<'EOF'
    """Check whether a file system is nearly full."""
    import shutil


    def check_disk(path, limit=0.8):
        """Return True if path is more than limit (0 to 1) full."""
        total, used, _free = shutil.disk_usage(path)
        return used / total > limit


    if __name__ == "__main__":
        print(check_disk("/"))
    EOF
    flake8 messy.py && echo "flake8: no problems"
    python3 messy.py
    ```

    ```{.output}
    flake8: no problems
    False
    ```

    ::: explain

### Exam corner

- Use **Python 3** (`python3`); Python 2 is end-of-life. Ubuntu 24.04 ships Python 3.12.
- **Indentation** defines code blocks; a line ending in `:` starts a block; PEP 8 says 4 spaces.
- Data types: **integer** (`int`), **floating point** (`float`), **string** (`str`), **Boolean** (`True`/`False`), **list** (`[ ]`, ordered), **dictionary** (`{key: value}`).
- **Built-in modules** (standard library) need no install: `os`, `sys`, `subprocess`, `shutil`, `pathlib`, `json`, `argparse`, `datetime`, `re`, `logging`, `socket`.
- A **module** is a `.py` file; a **package** is a directory of modules with `__init__.py`. Use them with `import x` or `from x import y`.
- **Virtual environment**: `python3 -m venv venv`, `source venv/bin/activate`, `deactivate`. Ubuntu needs `python3-venv`.
- **pip install** packages from PyPI inside a venv; `pip freeze > requirements.txt` records **dependencies**; `pip install -r requirements.txt` restores them.
- `error: externally-managed-environment` (PEP 668) means pip will not modify the system Python: use a venv, `apt install python3-xyz`, or `pipx`.
- **PEP 8** is Python's style guide: 4-space indents, 79-character lines, `snake_case` functions and variables, `CapWords` classes, `UPPER_CASE` constants, imports at the top. Check it with `pycodestyle` or `flake8`.
- `if __name__ == "__main__":` runs code only when the file is executed directly; `sys.exit(n)` sets the exit status.
